# Device compatibility

The reference treadmill is an Athletic Works YK-03K45 with a FitShow FS-BLE-V3X module, based on operator-provided context and prior app observations. The available evidence includes FTMS services, protocol responses and speed/distance notifications. It does not establish calibrated speed, physical stop behavior or general compatibility with other models. Original observations remain private with their dates and environments.

FTMS is preferred where the device supports it. FitShow-specific behavior is included only where observations identify the vendor protocol and the feature requires it. UUID similarity alone does not establish protocol compatibility. See [protocol references](../../shared/README.md) and [hardware evidence requirements](../testing/hardware.md).
