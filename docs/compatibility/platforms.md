# Platform status

| Platform | Status | Scope |
| --- | --- | --- |
| iOS | Implemented | VaganciaFitness workout product and VaganciaFitnessDebug diagnostics; minimum iOS 26 |
| watchOS | Implemented companion | Workout capture and HealthKit integration; minimum watchOS 26; no treadmill motor control |
| Android | Future work | No app, build, runtime, or CI support is present |

A platform listed as implemented still requires checks against its supported OS and devices. Use [software checks](../testing/software.md) for source validation and [hardware evidence](../testing/hardware.md) for device observations; neither substitutes for the other.
