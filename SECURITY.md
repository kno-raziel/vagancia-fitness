# Security reports

This repository distributes source code. Use the repository's GitHub Issues for bugs, questions and security-related reports.

Include the affected component, source revision, platform and a minimal synthetic example where possible. Issues are public: omit credentials, private diagnostic exports, health data, device identifiers and personal information. Describe security concerns without publishing ready-to-use exploit details.

GitHub Issues is the supported reporting channel. The project does not offer a private reporting service. It is maintained by one individual and does not promise response times or ongoing security support.
